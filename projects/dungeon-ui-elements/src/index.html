dungeon-ui — Web Components bundle

This page is a build artifact host. To use the bundle, load main.js from any host page:

<script type="module" src="https://dungeon-ui-elements.pages.dev/main.js"></script>
<dg-button label="Save" severity="primary"></dg-button>

Tags registered after this script loads: dg-button, dg-input-text, dg-input-number, dg-input-group, dg-input-group-addon, dg-icon-field, dg-input-icon, dg-dialog, dg-table, dg-paginator, dg-checkbox, dg-radio, dg-dropdown, dg-autocomplete, dg-datepicker, dg-nav-menu.

Live demo on the showcase site: elements-example.html.
